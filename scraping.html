Projet web-scraping

CNAM, Reims · Novembre 2024

Contexte

Un projet réalisé au CNAM de Reims, centré sur la collecte automatisée de données financières publiques, pour se confronter concrètement à un pipeline complet : extraction, structuration, puis stockage de données issues du web.

Ce que fait le projet

Le projet met en place un pipeline de web-scraping qui va chercher des données boursières sur des pages web, les nettoie et les structure, puis les enregistre dans une base de données relationnelle pour pouvoir les exploiter par la suite.

  • Extraction automatisée de données boursières depuis des pages web
  • Nettoyage et structuration des données collectées
  • Stockage en base de données relationnelle
  • Hébergement du pipeline sur un serveur Apache

Mon rôle

Conception et développement du pipeline de bout en bout, du script de collecte jusqu'au schéma de la base de données, avec une attention particulière portée à la fiabilité de l'extraction face aux évolutions des pages sources.
